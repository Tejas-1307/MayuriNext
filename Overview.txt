1. EXECUTIVE SUMMARY & NON-TECHNICAL OVERVIEW
================================================================================

1.1 WHAT IS MAYURI LANDMARKS?
-----------------------------
Mayuri Landmarks is a modern, high-end real estate web application crafted to showcase 
premium residential townships, commercial hubs, luxury villas, and bespoke interior 
design services. 

It transforms standard static real estate listings into an immersive, interactive digital 
experience. Visitors can explore architectural designs, view floor plans, schedule on-site 
property tours, browse real home interior showcases, and submit inquiries seamlessly.

1.2 BUSINESS GOALS & OBJECTIVES
-------------------------------
• Digital Transformation: Establish a top-tier digital presence for Mayuri Landmarks 
  that reflects luxury, trust, and structural elegance.
• Lead Generation: Convert casual site visitors into high-intent buyers through integrated 
  site-visit schedulers, instant inquiry forms, and brochure downloads.
• Interactive Product Discovery: Allow prospective buyers to visually interact with 
  building skylines, flat configurations, floor plans, and amenity highlights.
• Brand Building: Communicate key milestones (300+ units, years of experience, customer 
  satisfaction) to foster credibility and trust.

1.3 TARGET AUDIENCE
-------------------
• Premium Homebuyers: Individuals and families looking for luxury apartments, 
  townships, and villas.
• Real Estate Investors: Buyers looking for high-value residential and commercial properties.
• Commercial Clients: Business owners looking for modern office and retail spaces.
• Interior Design Seekers: Homeowners seeking end-to-end customized home interior solutions.

1.4 KEY VALUE PROPOSITIONS
--------------------------
• 3D Interactive Skyline: Unique layered visual presentation of Mayuri towers on the homepage.
• Seamless Site Booking: Easy step-by-step form to book personalized physical site tours.
• Custom Interior Visualizer: High-definition interior gallery with dynamic animation styles.
• Responsive & Dark/Light Adaptive: Flawless experience across smartphones, tablets, 
  and desktop monitors with custom light and dark color schemes.

2. CORE FEATURES & USER EXPERIENCE
================================================================================

2.1 PREMIUM PRELOADER & ENTRANCE ANIMATION (Loader.jsx)
• Displays an elegant logo preloader screen while initial assets load in the background.
• Features an animated progress percentage indicator and smooth curtain reveal transition, 
  setting a sophisticated tone from the moment the user visits the website.

2.2 INTERACTIVE 3D TOWER SKYLINE HERO SECTION (Home.jsx)
• Layered parallax representation of flagship Mayuri developments (e.g., Mayuri Infinity, 
  Mayuri Optimum Phase 2, Mayuri Adhinathpuram, Mayuri Elite).
• Hovering over any tower highlights the building structure, presenting quick metadata 
  cards with project type, location, unit counts, and a direct button to inspect the project.

2.3 PROJECT PORTFOLIO & SMART CATEGORY FILTERING (Projects.jsx)
• Categorized catalog of properties allowing users to filter by:
  - All Projects
  - Residential Townships
  - Commercial Hubs
  - Luxury Villas

  navigation to detailed project insights.

2.4 COMPREHENSIVE PROJECT DETAILS PAGE (ProjectDetails.jsx)
• Route: `/project/:id`
• Deep dive into individual developments featuring:
  - Image carousel & gallery
  - Interactive floor plan viewer (1 BHK, 2 BHK, 3 BHK, Penthouse layouts)

  - Choose convenient time slots (Morning, Afternoon, Evening).

3. TECHNICAL ARCHITECTURE & SYSTEM DESIGN
================================================================================

3.1 SPA ARCHITECTURE
The application is built as a Single Page Application (SPA) using React 19 and Vite. 
All assets and JavaScript bundles are optimized for minimal payload size and rapid 
Initial Page Load (FCP) and Time to Interactive (TTI).

3.2 ROUTE ARCHITECTURE (react-router-dom v7)
• `/` - Main single-page scroll layout containing Navbar, Hero, Projects, Amenities, 
  Testimonials, Why Us, Services, Contact, and Footer.
• `/project/:id` - Dynamic route displaying deep project specifications based on project ID.
• `/service/:id` - Dynamic route displaying detailed service info based on service ID.
• `/interiors` - Dedicated full-page interior design visualizer gallery.

3.3 ANIMATION & PHYSICS ENGINE ARCHITECTURE
• GSAP (GreenSock Animation Platform) + ScrollTrigger: Drives complex timeline 
  animations, parallax building movement in the hero section, scroll-based element reveals, 
  and subtle hover micro-interactions.
• Lenis Smooth Scroll (@studio-freight/lenis): Intercepts native mouse wheel scroll events 
  to provide smooth momentum-based scrolling across complex visual pages like `/interiors`.
• Framer Motion: Powers component-level enter/exit transitions, modal popups, and tab switching.

3.4 DYNAMIC ASSET IMPORT PIPELINE
The `/interiors` gallery utilizes Vite's native module glob feature:
`import.meta.glob('../../assets/Flats_Img/*.{jpeg,jpg,png,webp}', { eager: true })`
This allows newly added images in the directory to automatically populate in the UI 
without manual import statements in code.

3.5 DARK/LIGHT THEME AUTOMATION SCRIPT (theme-script.cjs)
A custom Node.js script `theme-script.cjs` processes JSX component templates to systematically 
inject Tailwind CSS v4 dark mode class variants (`dark:bg-[#080808]`, `dark:text-white`), 
ensuring seamless theme adaptability across legacy and new UI modules.

6. DEVELOPMENT & MAINTENANCE GUIDE
================================================================================

6.1 SYSTEM PREREQUISITES
• Node.js: Recommended version v18.0.0 or higher.
• npm: Package manager (comes bundled with Node.js).

6.2 INSTALLATION & SETUP
1. Open terminal/command prompt in the project root directory.
2. Run `npm install` to install all required dependencies listed in `package.json`.

6.3 AVAILABLE CLI SCRIPTS
• Start Development Server:
  `npm run dev`
  Launches the local Vite server with Hot Module Replacement (HMR) at http://localhost:5173.

• Build for Production:
  `npm run build`
  Compiles and optimizes all React JSX, CSS, and JS assets into the `dist/` directory ready for deployment.

• Preview Production Build:
  `npm run preview`
  Serves the compiled production bundle locally to test production readiness.

• Code Linting:
  `npm run lint`
  Runs ESLint across all source files to verify syntax and code standard compliance.

6.4 CUSTOM THEME SCRIPT EXECUTION
To automatically process component files for dark/light mode class injection:
  `node theme-script.cjs`
